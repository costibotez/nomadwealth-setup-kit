When a checkpoint fails

Troubleshooting without guessing.

Keep secrets out of screenshots and support tickets. Start with the exact Vercel deployment, browser, and Neon logs involved.

Database connection fails

Confirm DATABASE_URL exists in the Vercel environment serving the deployment, uses a pooled Neon connection, and has not been renamed with a custom prefix. If you pasted a URL into the wizard, check it locally and rotate it if it appeared in a screenshot or chat.

“SESSION_SECRET is not set”

Generate a new random value, add it to the same Vercel environment as Production, and redeploy. The middleware fails closed without it. Do not use a portfolio identifier, password, or a value reused by another service.

Setup token rejected

Check that the value in the wizard exactly matches SETUP_TOKEN in the deployed environment. Environment changes require a new deployment. If the token was exposed, replace it before continuing.

Redirect loop or setup page disappears

A configured install redirects away from setup and its setup APIs return 403 by design. If a fresh deployment is not reaching setup, check the deployment’s database status and the nw_configured cookie by opening a private browser window. Do not forge the cookie; it is only a warm-request shortcut and is not authentication.

Migrations fail

First verify database reachability, then inspect the deployment logs for the migration error. Do not run drizzle-kit against a production buyer database as a first response; the app uses embedded runtime migrations. Restore from Neon only after preserving the error and backup context.

Cron returns 401

Set a buyer-owned CRON_SECRET in the Vercel environment and confirm the scheduled request sends the matching Bearer token. Never put the secret in a URL, a public issue, or this site.

Import refuses a file

The browser importer supports CSV/XLSX/XLS and refuses files over 15 MB. Export a smaller file, inspect the first worksheet, and confirm columns are mapped to the intended asset class. A malformed source export is safer to correct before import than to “make fit” by guessing.

License key missing or rejected

Search the purchase email for “NomadWealth license” and verify the key without sharing it. You can finish on Lite and activate later. For delivery help, contact support@nomadwealth.app; do not include the key in the email subject or body.

Stop if a secret leaked. Rotate the affected database credential, Vercel variable, license token, or API key before investigating further. Redaction after the fact is not rotation.
