Setup Kit / Privacy

A clear boundary

This guide collects nothing.

The Setup Kit is a static documentation site. Its purpose is to explain how you deploy NomadWealth on infrastructure you own.

What this site does not have

  • No forms or login flow.
  • No analytics, advertising pixels, consent cookies, or local storage.
  • No database, server action, API route, or account record.
  • No third-party scripts, fonts, embeds, or runtime network calls.
  • No request for your DATABASE_URL, password, license key, API key, bearer token, or financial export.

What the guide contains

It contains setup instructions, safe placeholders, links to public product documentation, and the public Vercel deploy-template link. The URL is marked noindex to reduce search discovery, but that is not access control.

Anyone who knows the URL can read it. Do not add purchaser-specific content or treat the link as proof that a visitor owns a license. The kit is safe to publish because it contains no secrets.

NomadWealth application privacy

The application itself runs in the buyer’s Vercel account and stores financial data in the buyer’s Neon database. This separate site does not connect to either. For the product’s architecture and self-host security model, read the public security page ↗.

Reporting an issue

If you find a possible disclosure, do not send the secret in a report. Rotate it first, then describe the affected page or repository path to security@nomadwealth.app.
