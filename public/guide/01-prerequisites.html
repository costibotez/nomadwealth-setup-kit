Setup Kit / Prerequisites

01 / Prepare

Get your accounts and secrets ready.

You do not need a local Node installation. You need accounts you control, a password manager, and a few random values generated locally.

Never paste secrets into this website. Generate and store them in your password manager or directly in Vercel. The examples below are commands, not fields to fill in here.

Have these ready

  • A Vercel account and a team where you can create a project.
  • A Neon account. The Vercel Marketplace integration can create the database for you.
  • A password manager for SESSION_SECRET, SETUP_TOKEN, and your dashboard password.
  • A private GitHub repository for your deployed source. The deploy flow starts from the public template and creates your copy.

Generate the two setup secrets

Run these on your own computer, then store the output safely. Do not send the output to support or paste it into this guide.

openssl rand -base64 48
openssl rand -hex 24

The first value is used for SESSION_SECRET. The second is a recommended SETUP_TOKEN that protects the unfinished wizard. You can generate equivalent values with your operating system’s password-manager generator.

Keep the boundary clear

This kit explains the product; it does not inspect your deployment. Do not provide this site with your Neon connection string, license key, owner password, recovery email, or portfolio export. The next pages tell you where each value belongs.
