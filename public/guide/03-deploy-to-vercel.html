03 / Deploy

Put the source in your account.

The one-click flow starts from the public deploy template, then creates a project and repository you control. The app itself runs in your Vercel account.

Deploy with Vercel ↗

If the button’s query parameters change in a future product release, use the button on the current NomadWealth public repository README instead of editing a URL by hand.

Deployment sequence

  1. Review the repository

    Confirm Vercel is cloning costibotez/nomadwealth from main. The template is public so the button can work; your resulting copy should be private.

  2. Name your project and repository

    Use a name you will recognise. Select the Vercel team that owns the install. Do not deploy into the Setup Kit project.

  3. Add Neon and variables

    Add Neon when prompted, then paste only the generated values described on the next page. Do not add vendor Stripe, campaign, or signing variables.

  4. Deploy Production

    After Vercel builds, open the generated vercel.app URL. An unconfigured install should lead to the setup wizard.

Keep the source private after cloning. The repository contains application source and future configuration may be sensitive. Never commit .env files or database exports.

No local install required

The one-click path builds on Vercel. You only need a local terminal if you want to generate random values or later maintain a fork. The guide never needs access to your GitHub, Vercel, or Neon credentials.
