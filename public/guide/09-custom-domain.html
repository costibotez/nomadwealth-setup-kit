Setup Kit / Custom domain

09 / Optional

Give your install a domain you recognise.

A custom domain is optional. The generated Vercel URL works; a domain can make bookmarks and household access easier to recognise.

  1. Add the domain in Vercel

    Open the NomadWealth project, go to Domains, and add a hostname you own, such as wealth.your-domain.example.

  2. Add the DNS record

    Use the exact record Vercel displays. A subdomain is commonly a CNAME, but do not guess if Vercel gives a different target. Remove conflicting records only after confirming what they serve.

  3. Wait for HTTPS

    Vercel provisions the certificate after DNS resolves. Test the HTTPS hostname before changing bookmarks or sharing access with anyone.

Keep the cockpit private. A custom domain does not replace the app’s password, session security, or two-factor authentication. Do not put a portfolio value or account name in the hostname.

Check it worked

  • HTTP redirects or is unavailable according to the Vercel domain configuration; use HTTPS for the final address.
  • The login page loads and the browser shows a valid certificate.
  • Unknown paths do not reveal private dashboard content without an authenticated session.
