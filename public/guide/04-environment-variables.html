Setup Kit / Environment variables

04 / Configure

Use your variables. Leave vendor variables out.

The buyer install should run with its own database and session secret. Extra integrations are optional and remain under the buyer’s control.

Do not copy values from this page. Place real values in your Vercel Project Settings or your own local environment. Never publish them or send them in a support ticket.

Required and buyer-owned

VariableUseGuidance
DATABASE_URLNeon pooled Postgres connectionInjected by the Neon integration or entered in your Vercel project.
SESSION_SECRETSigns login sessionsGenerate a long random value locally. Do not reuse it elsewhere.
SETUP_TOKENProtects unfinished setupRecommended during first run; remove after setup if you prefer.
DASHBOARD_PASSWORDLegacy fallback passwordOptional. The owner password saved by the wizard takes precedence.
CRON_SECRETAuthenticates scheduled jobsRecommended when using Vercel Cron; generate a separate random value.
CMC_API_KEYOptional crypto pricesOnly if you choose to bring your own provider key.

License and privacy settings

License activation is offline against the public key embedded in the app. The optional opaque revocation check sends only the key and fails open. To disable that check on your install, set LICENSE_API_URL to an empty value: LICENSE_API_URL="".

Never set these on a buyer install

NW_LICENSE_PRIVATE_KEY, STRIPE_WEBHOOK_SECRET, STRIPE_SECRET_KEY, STRIPE_LICENSE_PRODUCT_ID, RESEND_API_KEY, LICENSE_FROM_EMAIL, ALERT_FROM_EMAIL, CAMPAIGN_ENDPOINT, SETUP_KIT_URL, NEXT_PUBLIC_MARKETING_SITE, and vendor admin credentials belong only to the vendor deployment. Adding them does not unlock features; it creates an unsafe boundary.

How to check it worked

  • Vercel shows the variables only in the environments where you intend to use them.
  • The site reaches the setup wizard without a missing-session-secret warning.
  • No variable is committed to Git or pasted into the Setup Kit.
