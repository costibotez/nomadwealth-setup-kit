Setup Kit / Optional keys and cron

08 / Operate

Add integrations only when they earn their place.

The core app needs no vendor account at boot. Optional providers use keys you bring to your own deployment.

Keyless by default

FX

Frankfurter supplies exchange rates without a key. If it is unavailable, the app should make the failure visible rather than inventing a rate.

Stock prices

Yahoo-backed price lookups are keyless. Crypto pricing can use an optional buyer-owned CoinMarketCap key.

Notifications

Browser push is keyless. Email alerts require a Resend key in your own environment and are a Pro capability.

Scheduled jobs

Vercel Cron can call the install’s own endpoints for price refresh, alert checks, and the weekly digest. Set a buyer-generated CRON_SECRET; requests without the matching Bearer token fail closed.

openssl rand -hex 32

Do not paste the generated value into the Setup Kit. Add it to the appropriate Vercel environment and keep the cron configuration in the project you own.

What the jobs do

  • Refresh prices: retrieves configured prices and records the data needed for the cockpit history.
  • Check alerts: evaluates your own watchlist and sends configured browser/email notifications.
  • Weekly digest: prepares the scheduled summary if you enabled the relevant notification settings.

Optional means optional. Do not add a key because a guide mentions it. Start with the core app, then add one integration at a time and verify its privacy, cost, and failure behavior.
