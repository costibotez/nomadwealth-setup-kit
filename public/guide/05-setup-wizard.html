Setup Kit / Setup wizard

05 / Finish

Three steps to your first cockpit.

The wizard runs on your deployment. It checks your database, migrates your schema, optionally activates Pro offline, and creates the owner account.

  1. Neon — connect and migrate

    The wizard detects DATABASE_URL when Vercel has supplied it. If it is not present, it can accept a connection string for this unconfigured install. If SETUP_TOKEN is enabled, enter it first. Choose Test connection; the app verifies the database and runs the embedded migrations.

    Success looks like “Connected · schema migrated.” Setup routes are blocked after configuration.

  2. License — optional Pro activation and password

    Paste the Pro key from the purchase email if you have one. Activation is offline; no portfolio data is sent to a vendor. Leaving the key empty continues on the free Lite tier. Set a dashboard password of at least eight characters and optionally add a recovery email.

    The owner row stored in your database wins over the legacy environment fallback.

  3. Import — preview or start manually

    Choose a CSV/Excel file to preview and map, or choose Start manually. Spreadsheet parsing occurs in your browser. Nothing is uploaded merely by selecting a file. A selected import can be confirmed from the importer after the cockpit opens.

Finish safely

Click Finish & open cockpit. The completion route verifies the password you just created, records setup completion, signs your session, and redirects to the dashboard or importer. If the password is rejected, return to the password step rather than trying random values.

Do not share the setup URL as proof of ownership. Until setup is complete, a fresh deployment is an exposed public URL. Use SETUP_TOKEN, finish promptly, and keep the Vercel project private to your team.

First check in the cockpit

  • Open Settings and confirm the owner password and security options.
  • Enable two-factor authentication when available to you.
  • Confirm the currency and timezone choices before importing records.
  • Run the import preview and inspect mappings before committing.
