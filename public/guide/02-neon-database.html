Setup Kit / Neon database

02 / Store

Create the database before the app needs it.

NomadWealth uses Neon serverless Postgres. The database is provisioned in your Vercel and Neon accounts; the vendor does not receive a copy.

From the Vercel deploy flow

  1. Choose Neon

    When Vercel offers Marketplace products, add the Neon integration. NomadWealth reads the standard DATABASE_URL value.

  2. Choose a region

    Pick a region and jurisdiction you are comfortable with. This affects where the database is hosted and may not be easy to change later.

  3. Connect the project

    Connect the database to the Production environment. Preview is optional. Leave any custom variable prefix empty: the app expects the plain DATABASE_URL name.

Use the pooled connection string. Neon labels this as the connection string suitable for serverless applications. Keep it in Vercel; do not put it in GitHub or this kit.

Manual connection

If you already have a Neon project, copy its connection string from the Neon console’s Connect view and add it as DATABASE_URL in the Vercel project settings. The setup wizard can also accept a connection string for an unconfigured install, but Vercel environment configuration is the safer default.

How to check it worked

  • The Vercel project shows a connected Neon resource.
  • DATABASE_URL is present in the Production environment.
  • The next deployment reaches the NomadWealth setup wizard instead of an application error.
